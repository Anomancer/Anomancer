LIVE06 · Models

Model Routes

An agent and a model are different things.

The same agent can use an allowed model target without changing its authority. Provider-key configuration remains private.

LIVE07 · Tools

Tool Surface

A tool is not permission to use a tool.

A tool request passes through the server-side Tool Broker. Contract, capability, risk and human-only boundaries are checked before execution.

POLICY GATEDENY / HUMAN REQUIRED

Unknown or uncontracted tools are denied. A human-only action cannot become agent authority through a browser request.
