# Anomancer · Full Release 1.17.2

Nykyinen koottu full release on **1.17.2 Nanomancer**.

Se säilyttää 1.17.1 Archive Coren hallitun muistikerroksen ja lisää sen päälle ensimmäisen Capability Plugin -runtimen. Nanomancer vertaa Archive Objecteja, saman työtilan Run Recordeja ja rakenteista JSON-dataa deterministisesti ilman kielimallia tai automaattista kirjoitusoikeutta.

Analyysin tallentaminen Arkistoon on erillinen ihmisen hyväksymä toiminto.
