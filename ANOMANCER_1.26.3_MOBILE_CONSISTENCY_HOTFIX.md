# Anomancer 1.26.3 · Mobile Consistency Hotfix

This release is a focused visual-consistency pass over the Lighthouse Workbench mobile UI.

## Fixed

- Removed light/dark surface collisions from Core agent, tool, orchestra and run registries.
- Normalized agent-profile dialog body/header/footer and runtime controls in light mode.
- Fixed mobile “Työkalut ja reitit” buttons so labels and helper copy never concatenate.
- Normalized editorial orchestra cards, disclosures and machine-room surfaces in light mode.
- Tightened the workspace identity band while preserving readable context.
- Normalized the boot/loading screen to the active theme.

## Boundaries

`content/` and `media/` are intentionally unchanged from 1.26.2.
