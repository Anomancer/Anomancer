# Anomancer 1.18.0 · Full Release

**Release:** Mancer Runtime + Codemancer Reference Package

1.18.0 rakentuu 1.17.1 Archive Coren, 1.17.2 Nanomancerin ja 1.17.3 Arkistonhoitajan päälle. Julkaisun ydintesti on, että uusi domain-työtila voidaan asentaa package-sopimuksena ilman Codemancer-nimikohtaista Core Shell -navigaatiota.

## Mukana

- Mancer Package Spec v1 runtime
- fail-closed package validation
- Mancer Registry
- Codemancer 1.0.0 reference package
- geneerinen Schema Workbench
- geneerinen Mancer Artifact Store
- safe missing-package state
- package-local Approval Model, Agent Bindings, Orchestra Registry ja Archive Policy
- desktop + 360 px browser-portit
- serverless `mancers/**` bundlausraja

## Codemancerin työpinnat

`Project · Architecture · Code · Tasks · Tests · Runs · Review · Release · Documentation`

## Turvarajat

- ei Anomancerin julkisen contentin luku-/kirjoitusoikeutta
- ei automaattista repository-writeä
- ei automaattista releasea
- ei automaattista LLM-muistia
- human final authority säilyy
- package poistettuna workspace lukittuu fail-closed eikä rebindaudu toiseen domainiin
