# Anomancer 16.5.0 · Full Release

Julkaisu lisää Workspace Registry v2:n, Workspace Template Registryn, Constitution Contract v1:n, Artifact Boundary v1:n, Runtime Snapshot v4:n ja erilliset Työtila/Orkesteri-valitsimet 16.4 Lähetyskone-PWA:n päälle.

`default` säilyy teknisenä workspace-id:nä ja näkyy Anomancerina. Nykyinen Anomancer-editori, GitHub-sisältö, julkaisupäätös ja Vercel-output säilyvät. Uudet työtilat syntyvät fail-closed-tilaan ilman pääsyä Anomancerin sisältöön tai julkaisuadapteriin.

Asenna paketin `INSTALL_TO_CURRENT.sh`-skriptillä. Asennin säilyttää kohderepon kaikki sisältö-Markdownit ja mediat sekä ajaa koko regressiotarkistuksen ennen onnistumisilmoitusta.
