# Romancer / narrative-authoring domain

Romancer is the narrative-authoring workspace family. Legacy internal identifiers may still use `narramancer`, while the visible product name is Romancer.

Its domain model covers project/premise, world, characters, plot, chapters/scenes, timeline, canon/continuity, orchestration and export. Narrative agents operate under a narrative Constitution and do not inherit editorial publishing authority by default.

Artifacts are private workspace data. Export produces user-controlled project files and is not an automatic web publication path.

The narrative orchestration model uses premise, world, character, plot, scene, continuity, voice, critic and package roles with explicit runtime/workspace boundaries.
