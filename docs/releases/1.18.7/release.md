# Anomancer 1.18.7 — Public UI/UX Polish

This patch closes the public presentation issues reported after the 1.18.6 senior-audit release.

## Delivered

- Claims and evidence are available through a native, keyboard-accessible disclosure and remain closed by default.
- Candidate sources retain explicit status text without the former yellow highlight.
- Public Core headings, section spacing and roadmap copy use a calmer scale and current 1.18.7 state.
- Finnish and English Home/Core footers expose the private Admin route.
- The Dispatch index has a more compact hero, denser cards and a quieter information hierarchy.
- Workspace cards use deep-link fallbacks. The visible Codemancer open action is covered by a browser click-through test.

## Authority boundary

This release does not expand agent authority, publication rights or the public data boundary. Admin remains authenticated, private and noindexed.
