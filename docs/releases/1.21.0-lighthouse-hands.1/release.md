# Anomancer 1.21.0-lighthouse-hands.1 — Lighthouse Hands

This construction release gives the Lighthouse shell bounded read-only capabilities before adaptive reasoning.

The capability router is provider-neutral. Runtime availability is resolved server-side. Public URL reads, optional search, explicit repository file reads and Mancer method activation are audited through D4, D5 and D6. All write-class external effects remain blocked from the Lighthouse route.

See `docs/architecture/lighthouse-hands.md` for the canonical boundary.
