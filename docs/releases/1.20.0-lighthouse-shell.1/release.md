# Anomancer 1.20.0-lighthouse-shell.1 — Lighthouse UX Architecture v2

This milestone turns the Lighthouse plan into an end-to-end application contract rather than another UI layer.

- Added local `Intent → ProblemModel → CapabilityResolution → WorkRecommendation → AuthorityDecision` routing.
- Added an explicit D0 preview and human Start gate before any external DeepSeek reasoning request.
- Added honest unresolved-capability reporting, including the currently unwired `research.search` capability.
- Added local text/Markdown/JSON/CSV material attachment and optional browser speech input at the Door.
- Replaced the five-button mobile depth strip with `Miksi? / Aineisto / Lisää` and a one-room-at-a-time deeper sheet.
- Kept desktop on the same D0–D6 ontology using its parallel inspector.
- Expanded the provider-neutral capability registry while keeping DeepSeek behind the adapter boundary.
- Added Problem Model, capability resolution, authority and recommendation contracts to Core provenance.
- Added architecture regression tests for D0 language, routing, human authority and mobile disclosure.
