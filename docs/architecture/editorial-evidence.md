# Editorial pipeline and evidence

The editorial workspace separates drafting quality from evidential authority.

## Pipeline

Editorial agents can research sources, structure material, draft, critique, adapt for audience/voice, classify claims and prepare publication packages. Agent count is not a truth guarantee; every stage remains bounded by contracts and validation.

## Evidence model

Claims and sources are represented separately from presentation. Evidence status can distinguish supported, interpretation and open/unsupported states. Source candidates are not automatically promoted to verified evidence.

The evidence presentation layer may render citations, source strips and visualizations, but presentation does not change the underlying claim/source relationship.

## Audience and language

Audience metadata and FI/EN boundaries are explicit content properties. Public filtering/presentation must not leak private editorial state or drafts.

## Human gate

Publishing remains an explicit human action. Agent orchestration can prepare a publication artifact but cannot silently cross the publication boundary.
