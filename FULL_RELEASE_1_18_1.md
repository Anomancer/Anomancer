# Anomancer 1.18.1 · Full Release

## Semantic Workbench Hardening

1.18.1 on 1.18.0 Mancer Runtime + Codemancer -julkaisun semanttinen ja UI/UX-kovetus.

Päämuutokset:

- Codemancerin Mancer-component CSS on nyt oikeasti tuotannon stylesheet-ketjussa ja browser-portissa.
- Romancer on käyttäjälle näkyvä nimi legacy Narramancer -tunnisteita rikkomatta.
- Codemancerin käyttöliittymä on suomenkielinen kone-id:iden pysyessä vakaina.
- tekniset ID:t, hashit ja sopimusmetadata on siirretty toissijaisiin details-näkymiin.
- Tarkistus ja Julkaisu näyttävät eksplisiittisen ihmisen toimivaltarajan.
- geneerisessä Mancer-kokoelmassa poisto on kumottavissa ennen tallennusta.
- Mancerin lokaali ja Core Shellin globaali tallennustila on yhtenäistetty.
- Arkiston ja Nanomancerin näkyvää protokollajargonia on selkeytetty.
- 360 px Core-nav sai tilaa ilman kolmatta pysyvää kromikerrosta.
- uusi Semantic Workbench -release-portti on mukana `npm run check` -ketjussa.

Katso `SEMANTIC_WORKBENCH_HARDENING_1_18_1.md`.
