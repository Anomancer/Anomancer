Agent Contract

Agentilla on versioitu rooli, työkalut, kirjoitusoikeudet, kiellot ja budjetti. Prompti ei yksin määritä identiteettiä.

LIVE02 · Agent Pool

Agent Registry

Agentit ovat sopimuksia, eivät hattuja.

Näkyvissä ovat vain julkiset sopimustiedot. Yksityisessä Core-ohjaamossa agentin voi kytkeä OFF ja tokenkattoa säätää sopimuksen rajoissa; promptit, oikeat ajot, sessiot ja salaisuudet eivät kuulu tähän näkymään.

LIVE03 · Orchestras

Orchestra Registry

Lähetyskone on ensimmäinen orkesteri.

Jokainen vaihe saa oman tehtävänsä. Orkesteri määrittää järjestyksen, evidenssipolitiikan ja ihmisen lopullisen päätösvallan.

LIVE ROUTER06 · Models

Model Routes

Agentti ja malli ovat eri asioita.

Core käyttää loogisia mallireittejä. Sama agentti voi käyttää sallittua DeepSeek-, OpenAI-, Anthropic- tai Gemini-targettia ilman että Agent Contractin toimivalta muuttuu. Julkinen näkymä ei kerro, mitkä provider-avaimet on konfiguroitu.

LIVE POLICY07 · Tools

Tool Surface

Työkalu ei ole lupa käyttää työkalua.

Työkalupyyntö kulkee palvelinpuolen Tool Brokerin läpi ennen oikeaa suoritusta. Sopimus, capability, riskitaso ja human-only-raja tarkistetaan fail-closed-periaatteella.

15.4 · POLICY GATETOOL403 / HUMAN REQUIRED

Tuntematon tai sopimukseen kuulumaton työkalu estetään. Human-only-toiminnot eivät muutu agenttioikeudeksi clientin pyynnöstä.

FOUNDATION08 · Usage
