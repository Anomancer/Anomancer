    ANOMANCER CORE / ASENNUS
    Avaa kuin oma sovellus
    

    1. Android / Chromium: avaa selaimen valikko ja valitse Asenna sovellus tai Lisää aloitusnäyttöön.
    2. Tietokone / Chromium: valitse osoiterivin asennuskuvake tai selaimen valikosta Asenna Anomancer Core.
    3. Firefox Linuxissä: asennuskehote ei välttämättä ole käytettävissä. Avaa Anomancer Core Chromium-pohjaisessa selaimessa asennusta varten.
    

    Asennus ei tallenna salasanaa tai API-avaimia laitteelle. Kirjautuminen tapahtuu edelleen suojattua palvelinyhteyttä vasten.
