# Anomancer 16.8.1 · Responsive Workspace Navigation

Tämä välirelease rakentaa 16.8.0 Core Shell Semantics -pohjan päälle yhden responsiivisen työtilanavigaation kaikille editoriprofiileille.

Keskeiset muutokset: template-ohjattu mobiilidokki, Narramancerin oikea puhelinkäyttöliittymä, yhteinen Lisää-bottom sheet, yhteinen overlay-controller, fokusrajaus / inert / Escape / fokuspalautus sekä mobiilin vähimmäiskosketus- ja typografiarajat.

16.8.1 sisältyy kokonaisuudessaan 16.8.2 full releaseen.
